# Canonical Model

CANONICAL is the durable spine for project memory, instructional packages, manifests, review queues, and export records.

The working hierarchy is:

- Program
- Module
- Session
- Session Brief
- Session Bundle
- Artifact
- Manifest

The file spine remains authoritative. The website and Base44 app mirror safe structured records so humans and agents can find, review, and reuse the work without losing the source package trail.

## Current Rule

Do not treat a generated packet as canonical until it has a classification, visibility scope, review status, and filing record.
