# Canonical Model

CANONICAL is the durable file spine and personal control surface for all filed work, prototypes, showcase material, and approved instructional records.

## Core principle

CANONICAL remains the source of truth. The Base44 portal mirrors structured records — it does not replace the file spine.

## Rails

- **AYA / CTS** — Institutional delivery rail for classroom-facing materials
- **PRISM** — Private instructional framework; facilitator intelligence stays private by default
- **CTS / RCS** — Public or open-source output layer

## Hierarchy

Program → Module → Session → Artifacts

Each session is anchored by a Session Brief that records the actual class state, not an idealized calendar stage.
