# Instructional Data Model

The instructional model is built around turning real class status into a durable Session Brief and then generating downstream artifacts from that brief.

## Core Records

- Program: top-level rail or framework.
- Module: course or unit inside a program.
- Session Brief: canonical state of one class/session.
- Session Bundle: generated package record for the session.
- Artifact: document, quiz, packet, slide outline, manifest, or adapter draft.

## Privacy Rule

Approved teaching outlines are available in the curriculum library. Private method records, local draft paths, and connected-service administration remain separate.
