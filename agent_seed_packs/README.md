# Agent Seed Packs

This folder contains owner-authored seed packs for Base44 agents and related CANONICAL instructional helpers.

## Current Pack

- `base44_agent_instructional_generator_seed_v1.json`

## Purpose

The seed pack teaches the PRISM / CANONICAL Program Helper how to normalize rough class notes into Session Briefs, AYA-safe outputs, PRISM facilitator outputs, bundle plans, and quality reports.

## Safety

Seed packs are source/config material, not runtime secrets. They must not contain API keys, OAuth tokens, connector credentials, local absolute paths, raw student data, backend logs, or uncurated private PRISM notes.

## Tracking Rule

Seed packs may be committed deliberately after review. Do not add new seed packs by blanket staging; inspect them first and confirm they are safe for the connected GitHub/Base44 app repo.
