# Artifact Recipes v0.1

## Lesson Plan Recipe

Required sections:

1. Title
2. Scope tag
3. Duration
4. Audience
5. Learning objectives
6. Materials
7. Opening script
8. Mini-lesson
9. Guided activity
10. Independent/student activity
11. Reflection
12. Assessment
13. Instructor notes
14. Evidence notes

## Student Handout Recipe

Required sections:

1. Plain-language title
2. Why this matters
3. Key idea
4. Example
5. Try it
6. Reflection
7. One next action

Rules:
- No clinical jargon unless defined simply.
- Do not label students as broken, lazy, unmotivated, or defective.
- Keep the page usable as a standalone worksheet.

## Facilitator Guide Recipe

Required sections:

1. Lesson purpose
2. Core concepts
3. Timing map
4. Script
5. Common student reactions
6. Reframes
7. Adaptations
8. Safety notes
9. Assessment notes

## Quiz Recipe

Question types:
- Multiple choice
- Short answer
- Scenario sort
- Reframe practice
- Application task

Quiz logic:
- Test concept understanding and application.
- Avoid trick questions.
- Include answer key and rationale.

## Slide Deck Recipe

Slide sequence:
1. Title
2. Why this matters
3. Core problem
4. Key concept
5. Example
6. Practice activity
7. Reflection
8. One next action
9. Exit ticket

Rules:
- Use large readable text.
- Avoid dense paragraphs.
- Use student-safe language.
- Keep evidence notes in speaker notes, not on crowded slides.
