# Assessment Plan v0.1

## Purpose

Track growth in self-efficacy, critical thinking, future-planning confidence, action initiation, and environmental awareness.

## Metrics

### 1. Dysfunctional Belief Reduction

Track shifts from:

- "I am late" to "I can start where I am."
- "Failure proves I am not good enough" to "Failure gives me data."
- "I need one perfect passion" to "I can follow curiosity and prototype."
- "I need motivation first" to "Small action can create momentum."

### 2. Prototype Frequency

Count monthly:
- Prototype conversations
- Prototype experiences
- Informational interviews
- Low-risk experiments

Target starter benchmark:
- At least 2 prototype actions per month.

### 3. Activation Latency

Track:
- Time between identified next action and first physical start.
- Number of completed two-minute entries.
- Number of five-second starts attempted.

### 4. Creative Confidence

Students self-rate:
- I can figure things out.
- I can try something before knowing everything.
- I can learn a new skill.
- I can recover from mistakes.
- I can ask for help.

Scale:
1 = Not true yet  
2 = Sometimes true  
3 = Mostly true  
4 = Strongly true

### 5. Critical Thinking

Students demonstrate:
- Can distinguish fact from argument.
- Can identify persuasive claims.
- Can name who they treat as authority.
- Can evaluate alignment and expertise.

## Evidence caution

Assessment data is educational progress information, not clinical diagnosis.
