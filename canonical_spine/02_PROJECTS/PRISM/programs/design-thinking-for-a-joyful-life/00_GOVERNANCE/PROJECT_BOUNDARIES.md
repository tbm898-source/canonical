# Project Boundaries

## Purpose

This file defines what belongs inside the Design Thinking for a Joyful Life project and how agents must separate general framework material from local implementation material.

## Included

- Life design curriculum architecture
- Youth development learning modules
- Critical thinking and authority-audit tools
- Self-worth and procrastination reframes
- Odyssey Planning and prototyping activities
- Activation and skill-acquisition tools
- Environmental architecture and peer group audits
- Decision-making and choice-overload tools
- Student-facing worksheets and reflection tools
- Instructor-facing facilitator guides
- Agent skill definitions
- Evidence tagging and source mapping

## Excluded unless explicitly requested

- Clinical diagnosis
- Mental health treatment plans
- Crisis intervention protocols beyond escalation language
- Private student records
- Identifiable student case notes
- AYA-internal staff conflict or HR material
- PRISM-private IP strategy inside public artifacts
- Live connector writes without owner approval

## Required tagging

Every generated asset must include one scope tag:

- `PRISM_CORE`
- `AYA_IMPLEMENTATION`
- `PRIVATE_OPERATOR`
- `PUBLIC_STUDENT_SAFE`
- `INSTRUCTOR_ONLY`
- `INTERNAL_AGENT_ONLY`

## Agent behavior rule

When uncertain, agents must default to the narrower, safer scope and place the output in `90_REVIEW`.
