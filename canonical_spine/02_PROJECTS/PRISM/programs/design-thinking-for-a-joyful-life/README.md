# Design Thinking for a Joyful Life

**Internal system name:** The Catalyst Blueprint  
**Canonical project slug:** `design-thinking-for-a-joyful-life`  
**Version:** v0.1 starter scaffold  
**Prepared:** 2026-05-25

## Purpose

This project reactivates a long-term PRISM/CANONICAL curriculum and agent-system branch focused on life design, self-mastery, critical thinking, and action-based confidence for youth ages 18-24.

The goal is to convert a proven human-led framework into a durable, agent-operable structure that can generate lessons, handouts, worksheets, quizzes, slide outlines, facilitator guides, reflection tools, and implementation packages while preserving source boundaries and evidence discipline.

## Core framing

Students are not broken. Many are operating from outdated internal scripts, hostile or unstable environments, shame-based performance beliefs, missing skills, limited support, or untested assumptions. The curriculum treats stuckness as something to examine, reframe, prototype, and redesign.

## Project rails

1. **PRISM_CORE**  
   Generalizable framework, concepts, agent logic, curriculum structures, artifact recipes, and assessment patterns.

2. **AYA_IMPLEMENTATION**  
   Local classroom/cohort implementation materials, staff references, Google Classroom outputs, schedules, and institution-specific details.

3. **PRIVATE_OPERATOR**  
   Internal strategy, IP boundaries, connector logic, Base44/Dropbox/ClickUp details, and agent governance.

## First build goal

Create a usable **Instructor Starter Kit v0.1** and **Agent Pack v0.1** that can be used by Base44, Codex, Cursor, or another agent environment to generate consistent materials without blending PRISM, AYA, and private operator content.

## Safety scope

This curriculum is developmental, educational, and coaching-oriented. It is not therapy, diagnosis, crisis response, or licensed mental health care. Agents must not diagnose mental health conditions or present practitioner tools as clinical laws.
